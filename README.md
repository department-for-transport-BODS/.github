# .github

This repository contains shared GitHub Actions and organisation-wide resources for the Department for Transport's Bus Open Data Service (BODS).

## Actions

| Action | Description |
|---|---|
| [`aws-login-assumed-role`](actions/aws-login-assumed-role/README.md) | Authenticates with the BODS Shared-Services account via OIDC then chains to assume a role in a target AWS account |
